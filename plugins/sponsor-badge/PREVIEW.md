# Plugin Preview: `sponsor-badge`

> Adds GitHub Sponsors and support buttons to help fund your open-source work.

## Live Rendered Output (Example: [@cmduyeen](https://github.com/cmduyeen))

## Support My Work

[![GitHub Sponsors](https://img.shields.io/badge/Sponsor-EA4AAA?style=for-the-badge&logo=github-sponsors&logoColor=white)](https://github.com/sponsors/cmduyeen)

## How to Enable

```bash
python setup.py --username <your-username> --plugins sponsor-badge
```
