# Plugin Preview: `profile-views`

> Adds a live profile visitor counter badge via komarev.com.

## Live Rendered Output (Example: [@cmduyeen](https://github.com/cmduyeen))

![Profile Views](https://komarev.com/ghpvc/?username=cmduyeen&color=3b82f6&style=flat-square)

## How to Enable

```bash
python setup.py --username <your-username> --plugins profile-views
```
