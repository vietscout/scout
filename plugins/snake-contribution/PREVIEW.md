# Plugin Preview: `snake-contribution`

> Generates an animated SVG snake eating your contribution graph daily via [Platane/snk](https://github.com/Platane/snk). Because the SVG is stored in your own `output` branch, it never suffers from third-party Vercel `503` outages.

## How to Enable

```bash
python setup.py --username <your-username> --plugins snake-contribution
```

Then run **Actions → Generate Contribution Snake → Run workflow** once in your `<username>/<username>` repository to generate the `output` branch.
