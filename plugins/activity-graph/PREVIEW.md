# Plugin Preview: `activity-graph`

> Renders a 31-day contribution line graph using github-readme-activity-graph.

## Activity Graph

[![cmduyeen's github activity graph](https://github-readme-activity-graph.vercel.app/graph?username=cmduyeen&theme=minimal)](https://github.com/cmduyeen)

## How to Enable

```bash
python setup.py --username <your-username> --plugins activity-graph
```
