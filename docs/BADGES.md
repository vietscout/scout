# Complete Catalog of GitHub Achievement Badges (100% Policy-Safe)

This reference covers every official **GitHub Achievement Badge**, **Profile Highlight**, and **Retired Badge**, along with legitimate ways to unlock them without risking account flags under GitHub's Acceptable Use Policies.

---

## 1. Active Achievement Badges

### 🦈 Pull Shark
- **Requirement:** Open pull requests that get merged.
- **Tiers:** Default (2) · Bronze x2 (16) · Silver x3 (128) · Gold x4 (1,024).
- **Legit way to unlock:** Fix typos in open-source documentation, improve READMEs, or manage your own projects using feature branches and PRs instead of pushing everything straight to `main`.

### 👯 Pair Extraordinaire
- **Requirement:** Co-author a commit in a pull request that gets merged, using the `Co-authored-by:` commit trailer.
- **Important:** The email address in `Co-authored-by: Name <email>` must belong to a real GitHub account.
- **Tiers:** Default (1) · Bronze x2 (10) · Silver x3 (24) · Gold x4 (48).
- **Legit way to unlock:** Pair program with a friend or teammate on a shared feature branch and credit them in the commit footer.

### 🚀 Quickdraw
- **Requirement:** Close an issue or a pull request within **5 minutes** of opening it.
- **Tiers:** Single-tier badge.
- **Legit way to unlock:** When you spot a quick fix or duplicate issue in your own project, open the issue/PR and resolve it right away.

### 🤠 YOLO
- **Requirement:** Merge a pull request **without a code review**.
- **Tiers:** Single-tier badge.
- **Legit way to unlock:** On your own personal project, open a PR for a real update and merge it directly without requesting an external review.

### 🧠 Galaxy Brain
- **Requirement:** Answer a question in **GitHub Discussions** (Q&A category) and have the author/maintainer mark your reply as the accepted answer.
- **Tiers:** Default (2) · Bronze x2 (8) · Silver x3 (16) · Gold x4 (32).
- **Legit way to unlock:** Browse `Q&A` tabs in tools/frameworks you already use and help beginners solve real issues.

### ⭐ Starstruck
- **Requirement:** Own a public repository that reaches the required star count.
- **Tiers:** Default (16) · Bronze x2 (128) · Silver x3 (512) · Gold x4 (4,096).
- **Legit way to unlock:** Build genuinely useful tools, starter kits, or localized utilities with clear documentation and screenshots.

### 💖 Public Sponsor
- **Requirement:** Sponsor an open-source developer or organization through **GitHub Sponsors**.
- **Tiers:** Single-tier badge.

## 2. Profile Highlights (Sidebar)

- **GitHub Pro:** Active GitHub Pro subscription (free for verified students via GitHub Education).
- **GitHub Developer Program:** Registered member of the GitHub Developer Program.

---

## 3. Retired Badges (No Longer Obtainable)

- **Arctic Code Vault Contributor:** Contributed to qualifying open-source repositories archived in the 2020 GitHub Archive Program snapshot.
- **Mars 2020 Helicopter Contributor:** Contributed to specific repositories used in NASA's Ingenuity Mars Helicopter mission.

---

## 4. Why You Should Never Use Badge-Farming Bots

Under **GitHub's Acceptable Use Policies (Spam and Inauthentic Activity)**, running scripts to push hundreds of empty commits or mass-open/merge fake PRs can trigger automated anti-abuse systems—resulting in ignored stats, profile flagging, or account suspension. Always earn badges through real workflows.
