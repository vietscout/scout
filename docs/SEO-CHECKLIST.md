# GitHub SEO & GEO Checklist

Optimize your GitHub profile and repositories so recruiters, developers, Google Search, and AI Search engines (ChatGPT, Perplexity, Google AI Overviews) understand your work immediately.

---

## 1. Profile Sidebar (First 5 Seconds)

- [ ] **Name:** Use your recognizable name or handle (e.g., `Your Name (handle)`).
- [ ] **Bio (1 line):** State what you build and your focus area (e.g., *"Minimalist builder crafting zero-install CLI tools and developer themes."*).
- [ ] **Website & Socials:** Link your personal blog/portfolio and active social handle.

---

## 2. The 6 Pinned Repositories Strategy

- [ ] Pin **6 flagship "gateway" repositories** instead of minor sub-repositories or forked tutorials.
- [ ] Balance your pins across your strengths (e.g., 1 flagship product, 1 theme/design system, 1 starter kit/guide, 1 blog/knowledge base).

---

## 3. Per-Repository SEO

- [ ] **Repository Slug:** Use clear, searchable kebab-case keywords (e.g., `pro-github-starter-kit`, `vietnamese-lunar-calendar`).
- [ ] **Description (~140–160 characters):** Include your primary keywords and value proposition cleanly—avoid generic phrases like *"My first repo"*.
- [ ] **Topics (up to 20):** Fill relevant topics mixing broad (`python`, `open-source`, `markdown`) and specific (`github-profile-readme`, `starter-kit`) tags.
- [ ] **Social Preview (`1280×640px`):** Upload a clean cover image under **Settings → General → Social preview** for rich link cards on X, LinkedIn, and Discord.

---

## 4. GEO (Generative Engine Optimization)

- [ ] Add an **`llms.txt`** file at the repository root summarizing key docs and purpose for AI agents.
- [ ] Use **structured Markdown tables** with clear headers for comparisons and catalogs.
- [ ] Include a **concise FAQ section** answering exact questions users ask AI search engines.
